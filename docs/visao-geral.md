# Visão Geral do Sistema

## 1. Objetivo
O objetivo deste trabalho é desenvolver uma documentação viva de requisitos e um protótipo evolutivo para um sistema de monitoramento de compromissos decenais da criança e adolescente. O sistema visa fornecer transparência e controle sobre as políticas públicas voltadas a esse público-alvo.

## 2. Descrição do Problema
Atualmente, o acompanhamento de metas públicas exige uma ferramenta estruturada. O sistema deverá apoiar o monitoramento desses compromissos decenais, permitindo a visualização hierárquica clara de: Problema Público ➔ Compromisso ➔ Objetivo ➔ Linha de Ação ➔ Tarefa ➔ Indicador.

## 3. Principais Funcionalidades
O sistema deverá permitir o acompanhamento de problemas públicos, compromissos, objetivos, linhas de ação, tarefas e indicadores, incluindo funcionalidades de busca, filtros, controle de usuários, exportação de dados, histórico de alterações e visualização de progresso. Além disso, deve garantir acessibilidade e controle rígido de permissões.
