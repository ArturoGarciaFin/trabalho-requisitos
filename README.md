## Descrição do Sistema
Este projeto é uma plataforma para o acompanhamento dos compromissos decenais da criança e do adolescente. O sistema permite a visualização hierárquica de problemas públicos, compromissos, objetivos, linhas de ação, tarefas e indicadores. Ele conta com recursos de filtragem, histórico de atualizações, níveis de acesso e exportação de dados, garantindo transparência e controle sobre as políticas públicas.

## Organização das Pastas
O repositório está estruturado da seguinte forma:
* **docs/**: Contém a documentação viva do projeto.
* **prototipo/**: Contém o protótipo.
* **entregas/**: Relatórios parciais de cada semana do projeto.
* **apresentacao/**: Arquivos utilizados na apresentação final.

## Resumo das Versões Entregues
* **Semana 1:** Definição de escopo, perfis de usuários e correção de inconsistências nos requisitos iniciais.
* **Semana 2:** Estruturação do backlog, priorização de histórias de usuário e definição das regras de negócio.
* **Semana 3:** Desenvolvimento da primeira versão do protótipo e criação dos casos de uso.
* **Semana 4:** Finalização do protótipo navegável, matriz de rastreabilidade, relatório de evolução e consolidação do repositório.
